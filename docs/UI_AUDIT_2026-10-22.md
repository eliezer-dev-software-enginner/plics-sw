# UI audit — 2026-10-22

Each of the 27 JSONC views was rendered in isolation with JavaFX and the Plics SW light theme. The audit used the initial window size from `AppRoutes` where a route exists, and 1200 × 620 for views without a direct route. It checked initial composition, clipping, legibility, spacing, and whether primary actions are visible. The screen actions were mocked, and all tables were empty; this does not validate populated data, navigation, printing, or database behavior.

| `categoria-list` | Search, actions, and table fit at 600 × 500. No layout change. |
